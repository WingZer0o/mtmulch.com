# Home-lab cluster (Flux GitOps)

The spare machine on the LAN (`192.168.50.226`) runs k3s. Flux, inside that cluster,
pulls this repo and deploys `k8s/overlays/homelab`. Nothing on the internet needs
access to the home network:

```
push code ──► GitHub Actions (homelab-images.yml) ──► GHCR images
                                                        │
          Flux image automation ◄── watches GHCR ───────┘
          commits new tag to k8s/overlays/homelab ──► Flux applies it to the cluster
```

| Path | Purpose |
|------|---------|
| `flux-system/gotk-components.yaml` | Flux controllers (generated by `flux install --export`) |
| `flux-system/gotk-sync.yaml` | The Git source (branch `homelab-flux`) and the root Kustomization |
| `apps.yaml` | Deploys the website from `k8s/overlays/homelab`, decrypting SOPS secrets |
| `image-automation.yaml` | Watches GHCR and commits the newest image tags |
| `bootstrap.sh` | One-time setup, run from WSL |

## One-time setup

**1. Install k3s on the lab machine** (over SSH):

```bash
curl -sfL https://get.k3s.io | sh -s - --write-kubeconfig-mode 644 --tls-san 192.168.50.226
```

**2. Copy its kubeconfig to WSL** on the dev PC, pointing at the LAN address:

```bash
LAB_USER=your-ssh-user   # your login on the lab machine
mkdir -p ~/.kube
ssh "$LAB_USER@192.168.50.226" cat /etc/rancher/k3s/k3s.yaml | sed 's/127.0.0.1/192.168.50.226/' > ~/.kube/homelab.yaml
chmod 600 ~/.kube/homelab.yaml
```

**3. Push the `homelab-flux` branch** so the image workflow runs once, then make the
three GHCR packages public (GitHub → your profile → Packages → each `mtmulch-*` →
Package settings → Change visibility → Public). Public images need no pull secret.

**4. Run the bootstrap** and add the deploy key it prints to the repo
(Settings → Deploy keys → Add, tick **Allow write access** — Flux commits image tags):

```bash
KUBECONFIG=~/.kube/homelab.yaml ./clusters/homelab/bootstrap.sh
```

**5. Open** https://192.168.50.226 and accept the certificate warning (Traefik's
built-in self-signed certificate; HTTPS is required for the app's `Secure` login cookie).

## Day to day

- Push to `homelab-flux` → images build → Flux updates the tag and deploys (~5–15 min).
- Watch it: `KUBECONFIG=~/.kube/homelab.yaml flux get all -A`
- Force a sync: `flux reconcile kustomization mtmulch --with-source`
- Edit secrets: `sops k8s/overlays/homelab/secrets.sops.yaml`, then commit.

## The age key

`~/.config/sops/age/keys.txt` on the dev PC is the **only** way to decrypt
`secrets.sops.yaml` (besides the copy in the cluster). Back it up in a password
manager. Never commit it.
